# Suggested commands

- Install: `pnpm install`.
- Type-check: `pnpm typecheck`.
- Build: `pnpm build`.
- Formatting: `pnpm format:check`; apply formatting with `pnpm format`.
- API development: `pnpm --filter @tracecaptcha/api dev`.
- API production start after build: `pnpm --filter @tracecaptcha/api start`.
- Windows shell is PowerShell; use `rg` for repository search.
- Current environment has npm offline mode and package retrieval did not complete; rerun install where registry access and write access to npm cache are available.
