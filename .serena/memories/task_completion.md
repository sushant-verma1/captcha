# Task completion

- For implemented TypeScript changes: run `pnpm typecheck` and `pnpm build` after dependencies are installed.
- Run `pnpm format:check` for formatting changes.
- For API contract changes: validate openapi.yaml with the chosen OpenAPI validator once installed and keep API examples aligned.
- Report files changed, commands actually run, commands not run and why, plus remaining security or compatibility assumptions.
- Do not mark a plan task complete until its stated Done when condition is met.
